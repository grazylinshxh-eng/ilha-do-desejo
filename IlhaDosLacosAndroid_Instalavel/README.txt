ILHA DOS LAÇOS — PROJETO ANDROID

Este projeto abre a V3 do jogo dentro de um WebView nativo e mantém:
- login e primeiro acesso
- localStorage
- troca de foto usando o seletor de arquivos do Android
- tema Sistema/Claro/Escuro
- votação e painel ADM

COMO GERAR O APK NO ANDROID STUDIO
1. Abra esta pasta no Android Studio.
2. Aguarde o Sync do Gradle e a instalação do SDK 35, se solicitada.
3. Menu Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. O APK de teste aparece em app/build/outputs/apk/debug/app-debug.apk.

IMPORTANTE: o APK atual continua local/offline. Cada celular terá seus próprios dados até o app ser conectado a um backend como Firebase/Supabase.
